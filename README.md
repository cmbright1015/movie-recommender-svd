# movie-recommender-svd

A movie recommendation system built with linear algebra on the MovieLens 100K data set, for MATH 344L: Applied Linear Algebra Lab.

## Data

This project uses the MovieLens 100K data set, downloaded when the notebooks run.

F. Maxwell Harper and Joseph A. Konstan. 2015. The MovieLens Datasets: History and Context. ACM Transactions on Interactive Intelligent Systems (TiiS) 5, 4, Article 19. https://doi.org/10.1145/2827872
